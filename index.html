About TEKZAA Renderer V7. This is a deterministic canvas-to-MP4 tool that runs entirely in your browser. It uses the WebCodecs API (VideoEncoder + VideoFrame) and an in-memory MP4 muxer to convert frame-by-frame canvas rendering into a downloadable H.264 MP4 file. No iframe, no external assets, no server upload.

Who is it for? Developers, animators, and generative artists who want to create reproducible video from code — motion graphics, data visualisations, algorithmic art, or automated content generation.

Why deterministic? Because every frame is computed solely from the time argument, the output is perfectly reproducible and frame-accurate. This is essential for video export, where a single dropped or duplicated frame ruins the result.

Frequently asked: Does it work offline? Yes, after initial load. What codecs are supported? H.264 (AVC) via WebCodecs. Can I use external images? No — embed as data URIs. Is there a file size limit? Limited only by browser memory. How do I get the best quality? Use 30–60 fps and a high bitrate (12–30 Mbps).

Technical contract: Your code must define window.TEKZAA_RENDER = function(time, ctx, width, height) { ... }. The function must draw the entire frame from scratch on each call, using only time for animation. Forbidden: requestAnimationFrame, setTimeout, setInterval, Date.now, performance.now, Math.random.

Stale-safe guarantee: Changing any setting (code, aspect, dimensions, duration, FPS, bitrate) automatically discards the previously rendered MP4 and requires a fresh render. The download button always delivers a video that matches the current settings.
